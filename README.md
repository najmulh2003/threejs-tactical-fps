Emberline is a round-based tactical FPS that runs in the browser: two teams fight over two bomb sites in a desert depot, with an economy, a buy menu, bots that push, hold, plant and defuse, and gunplay where stopping to aim pays.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
